# Zunox · Kit de marca

Los archivos oficiales de la marca **Zunox** y el manual de identidad.

**→ [brandkit.zunox.es](https://brandkit.zunox.es)**

## Qué hay aquí

| Carpeta | Contenido |
|---|---|
| `assets/svg/` | 4 bloqueos × 5 versiones de color. Para web y cualquier uso digital. |
| `assets/pdf/` | Vectorial para imprenta, rotulación y merchandising. |
| `assets/eps/` | Vectorial para proveedores con software antiguo. |
| `assets/png/` | 512 a 4096 px, fondo transparente. |
| `assets/favicon/` | `.ico`, apple-touch, Android, maskable y `site.webmanifest`. |
| `assets/social/` | Avatar, Open Graph y portadas de LinkedIn, X y YouTube. |
| `assets/color/` | Paleta en JSON, tokens CSS, Tailwind y equivalencias CMYK. |
| `assets/fonts/` | Sora y Manrope variables. |
| `descargas/` | Los mismos archivos empaquetados en ZIP. |

## Qué archivo uso

| Necesito | Uso |
|---|---|
| Web, app, email | `assets/svg/` — versión `-oscuro` o `-claro` según el fondo |
| Imprenta, rótulo, merchandising | `assets/pdf/` — nunca PNG |
| Proveedor que solo acepta EPS | `assets/eps/` |
| Sistema que no admite vectores | `assets/png/` del mayor tamaño que quepa |
| Favicon del sitio | `assets/favicon/favicon.ico` + `site.webmanifest` |
| Avatar de redes | `assets/social/avatar-400.png` |
| Miniatura al compartir enlaces | `assets/social/og-1200x630.png` |
| Serigrafía, bordado, grabado | versión `-blanco` o `-negro`, de una sola tinta |

## Cuatro reglas

1. **La Z es la primera letra de ZUNOX**, no un símbolo que se pone al lado.
2. **El verde `#00C389` no vale para texto sobre blanco** (2,13 de contraste, ilegible).
   Sobre fondo claro se usa `#00704F`, que pasa AA con 5,68.
3. **Para imprenta, PDF.** Convertir un PNG a vector estropea las proporciones.
4. **Usa el archivo, no lo redibujes.** Tampoco escribas «ZUNOX» con una fuente
   parecida: las letras del logo están dibujadas a medida.

Todo lo demás — área de respeto, tamaños mínimos, usos prohibidos — está en el
[manual de identidad](https://brandkit.zunox.es/manual.html).
